# GESP Programming Ability Syllabus (Grades 1-8)

This reference outlines the key topics and requirements for each GESP grade level. Use this to accurately tag "Syllabus Points" (考点) in your analysis.

## Level 1 (一级)
*   **Basics**: Computer history, hardware/software, binary representation, ASCII.
*   **Variables**: Variable definition, naming rules, basic data types (int, char, bool).
*   **Input/Output**: `cin`, `cout`, `scanf`, `printf`.
*   **Operators**: Arithmetic (+, -, *, /, %), assignment (=).
*   **Structure**: Sequential execution.

## Level 2 (二级)
*   **Control Structures**:
    *   **Selection**: `if`, `if-else`, `switch`.
    *   **Loops**: `for`, `while`, `do-while`, nested loops.
*   **Logic**: Logical operators (&&, ||, !), relational operators (==, !=, <, >).
*   **Algorithms**: Basic counting, summation, max/min finding within a loop.
*   **Math**: Simple digit extraction (mod 10).

## Level 3 (三级)
*   **Arrays**: One-dimensional arrays (declaration, access, traversal).
*   **Strings**: Character arrays, string functions (strlen, strcpy, etc. or std::string basics).
*   **Sorting (Basic)**: Bubble sort, Selection sort, Insertion sort.
*   **Number Theory**: Prime numbers, Factors, GCD (Greatest Common Divisor), LCM (Least Common Multiple), Sieve of Eratosthenes.
*   **Encoding**: Binary to Decimal, Hexadecimal conversions.

## Level 4 (四级)
*   **Functions**: Definition, declaration, calling, parameter passing (value vs. reference), return values, variable scope (local vs. global).
*   **Data Structures**: Structs (composite data types), basics of Classes.
*   **Arrays**: Multi-dimensional arrays (2D matrices).
*   **Algorithms**: Simple recursion, more complex simulation problems.
*   **Complexity**: Basic concept of Time Complexity (Big O notation).

## Level 5 (五级)
*   **Recursion**: Deep understanding of recursive functions.
*   **Search**: Linear search, Binary search (concept and implementation).
*   **Sorting (Advanced)**: Concepts of Merge Sort, Quick Sort (std::sort usage).
*   **Algorithms**:
    *   Greedy Algorithm basics.
    *   Simple Dynamic Programming (DP) concepts (e.g., Fibonacci, climbing stairs).
    *   High-precision arithmetic (Big Integer addition/subtraction).
*   **Bitwise**: Bitwise operators (&, |, ^, ~, <<, >>).

## Level 6 (六级)
*   **Pointers**: Pointer definition, address operator (&), dereference (*), pointer arithmetic.
*   **Data Structures**:
    *   Linked Lists (singly, doubly).
    *   STL Containers: `std::vector`, `std::string`, `std::pair`.
*   **File I/O**: `freopen`, file streams.
*   **Algorithms**:
    *   Breadth-First Search (BFS) basics.
    *   Depth-First Search (DFS) basics.
    *   Backtracking (e.g., N-Queens, permutations).

## Level 7 (七级)
*   **Trees**:
    *   Binary Trees (properties, traversals: pre/in/post-order).
    *   Binary Search Trees (BST).
    *   Heap (Priority Queue).
*   **Graphs**:
    *   Graph representation (Adjacency Matrix, Adjacency List).
    *   Graph Traversal (BFS, DFS on graphs).
*   **Algorithms**:
    *   Knapsack Problem (0/1, Complete).
    *   Interval DP, Linear DP.

## Level 8 (八级)
*   **Advanced Graphs**:
    *   Shortest Path (Dijkstra, Floyd-Warshall, SPFA).
    *   Minimum Spanning Tree (Prim, Kruskal).
    *   Topological Sort.
*   **Advanced Data Structures**:
    *   Union-Find (Disjoint Set Union).
    *   Segment Trees, Fenwick Trees (BIT).
*   **Computational Geometry**: Basic vector operations, cross product, point/line relationships.
*   **String Algorithms**: KMP (optional/advanced).
