# 项目课例验证

日期：2026-10-29；版本：0.7.0-dev。原始任务与所有课程内容均自编，没有真实学生数据。

## 设计与内容人工核对

- source明确0<=N,M<=20、初始状态、每轮动作、输出位置和结束文字；主任务与迁移均保留完整五字段题面。
- 需求由“一次充能后还未达标”引出，先手工检查0→1→2→3，再对应while条件、更新与返回检查；末尾提炼规则并迁移为逐次消耗氧气。
- 常规时间10+12+13+15+13+15+8+4=90分钟；独立15分钟、迁移8分钟、退出检查4分钟。超时取舍保留这些证据，不预填孩子已会。
- V1/V2固定观察输出0/1，与V3正式输入输出分开；教师允许提供两行初值，核心循环由学生实现。功能、解释、独立、迁移各自待取得。
- 故意错误片段因只算不存会在正目标下无限重复，正文明确仅纸面三轮追踪，没有运行该片段或把它写成标准程序通过。

## 程序实测

运行前逐块审阅，显式cases.json覆盖4个Python代码块，共10个用例：

| 对象 | 用例与预期 | 结果 |
| --- | --- | --- |
| V1 | 无输入，输出0 | 一致 |
| V2 | 无输入，输出1 | 一致 |
| 主任务 | N=3公开样例、N=0零次、N=1一次、N=20上界；先逐次输出1..N，再输出完成 | 4组一致 |
| 迁移 | M=3公开样例、M=0零次、M=1一次、M=20上界；逐次输出M−1..0，再输出结束 | 4组一致 |

输出按完整字符串比较，保留中文、空格和换行。预期依据任务与手算，未从待测输出反推。没有跳过支持语言代码块；plain中的故意错误只作为已标明的手工实验。

课例调用结果位于忽略的.local/project-teaching-validation/example-runtime.json。现有检查器静态模式只检查围栏，显式--cases才执行；不等于Obsidian渲染或真实课堂检验。
