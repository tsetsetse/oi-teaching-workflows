# 按语言与学习阶段适配

只读取当前需要的路径；以本次课程实际前置为准，不按语言推定年龄、知识范围、兴趣或竞赛目标。

## Python：各知识点的情境学习

覆盖本次课程范围内的基础语法、容器、函数及后续综合应用。Turtle结课衔接可以用图形/纸卡连接状态与执行；已经进入文本程序的学生同样可通过情境学习新知识，不要求返回Turtle或添加图形库。

| 学习内容 | 可选需求方向 | 应观察的机制 |
| --- | --- | --- |
| 变量、表达式 | 属性记录、预算与计费 | 当前值、数量关系、计算与保存 |
| 输入与转换 | 使用者定制任务 | 外部文字如何成为需要的数据 |
| 条件、循环 | 按规则响应、重复处理 | 条件、分支选择、状态更新与停止 |
| 字符串、列表等容器 | 信息整理、多项记录 | 字符/元素、位置、遍历与修改 |
| 函数 | 增加功能、复用一段操作 | 职责、参数、返回值与调用过程 |

这些是选题线索，不是固定课程顺序或完整题面。比如只教while时，图片、随机数、事件库和复杂校验可以不加入；允许输入的前提写清，再在后续目标确需时学习校验。每个核心新机制都要从需求推到代码，不能把未学的核心能力藏在教师外壳中再记学生已会。

## C++：按课程深度选择要求

| 阶段 | 项目组织与验收深度 |
| --- | --- |
| 基础语法 | 从计数、记录、判断等具体需求引出本课语法；通过逐句状态和短反例解释，不机械要求复杂证明或优化方案 |
| 算法应用 | 情境→输入输出/范围→手算→状态/模型→直接方法→瓶颈/优化→正确性、复杂度与实现 |
| 综合实践 | 在已学范围内拆职责和接口、安排模块与集成测试；按本次目标允许的语法组织，不突然引入框架/高级模板 |

统一本次编译版本、允许头文件/语法和平台I/O要求，交接时这些优先于被调用技能的默认版本。代码优先清楚的变量、数组、循环、条件、简单函数/结构和已学STL；按本课目标检查初始化、整数范围、除法含义、下标与边界，不一次塞进全部语言细节。

课堂带提示演示与正式提交的输入输出分别标注；从角色或生活故事中明确处理对象、操作、关系、输入输出和数据约束。根据最大数据决定是否需要优化：如大量区间查询可以比较逐段累加与前缀和，数值范围决定累计类型；证明和复杂度围绕所选方法，而非附加术语。

教学分层说明每层能完成什么功能、适用哪些条件及学生独立范围；不同版本不自动拥有考试分数。对真实GESP/CSP题目，原卷解析交contest-exam-analysis，按真实测试点、分组与规则分析，各方案有完整实现。缺评分依据只说能力边界，不能推测“基础版可拿多少分”。

## 跨语言共同检查

版本的状态与输出对应同一任务；教师支持和学生实现分别标注；功能、解释、独立、迁移均保留。仅制作作品时评价实现，只有取得学生作答/观察后才能评价学习。换语言不等于自动取得同阶段知识，输入或代码版本变化时重新核对受影响的资料与测试。
