# 自编原始输入：探测器充能助手

任务：制作90分钟Python项目课，引入while。学生已经能使用变量、整数加减、print、input、int与if，比较大小也已学；尚未学循环、函数定义、容器或随机数。这里是课程前置假设，没有真实学员表现记录。

允许教师提供标题、图片、变量拼写和起始代码；目标知识中的条件、循环范围与更新需要学生理解。只做纸面/控制台课例，不制作PPT、网页或图形界面。

已确认自编主任务：初始能量0，读入目标整数N，0<=N<=20；每轮充能1，达到目标时停止，每次充能后输出当前能量，最后输出一行中文“完成”。N为0时只输出“完成”。不显示输入提示、初始能量或其他文字，不加入真实时间等待。输入只有一行N。

主任务样例：N=3时依次输出1、2、3、完成，各占一行；N=0时只输出完成。状态示范使用0→1→2→3。

已确认自编迁移任务：读入氧气格数M，0<=M<=20；每次行动消耗1格，消耗后输出剩余格数，到0时停止，最后输出一行“结束”。M=0时只输出结束。输入只有一行M，不显示提示文字。

迁移样例：M=3时依次输出2、1、0、结束，各占一行。教师先收起主任务完整代码，迁移时不提供循环模板；学生实际能否完成待取得证据。
