## 问题卡：从1开始时遗漏最后一次执行

### 具体表现与机制

S1在Q1使用 `i=1;i<n;i++`，执行时i只取1到n-1，所以输出n-1行。n=1时第一次判断即失败，输出为空；n=3时只有两行Hello；n=5时只有四行。这是条件与任务“恰好n次”不一致的具体机制。

这不能推出所有循环概念都未掌握，也不能把所有题的 `<` 都改成 `<=`。需要确认的关系是：起点、是否包含终点、更新方式共同决定执行次数。O2表明本次首次未先检验n=1，尚不能推断长期测试习惯。

### 下一步具体教学改动

在本课“循环执行顺序”讲解后补一个端点对照环节：先让学员独立预测n=1、3、5的输出次数，再列n=3时i的判断/执行/更新表；对照从1到n与从0到n-1两种均执行n次的写法。先不展示答案，由学员指出最后执行值和首次失败判断值。

预计用约12分钟进行预测、追踪与解释，实际按独立复验表现调整。教师先用原题追问，再撤除提示做下面的练习。若后续需要修订讲义或演示，改动位置是循环顺序后的端点对照与边界检查，而不是重做整课；该调整尚未实施。

### 需补练的知识关系

1. 从1开始、包含n，每次加1，执行n次。
2. 从0开始、不包含n，每次加1，也执行n次；`<`在这一任务中正确。
3. 从n向1递减、包含1，初始化、判断与更新要共同变化。
4. n=1是有效输入，能暴露“第一次判断就退出”的问题；预测和实际运行要分别记录。

## 补练P1：原题独立复验

目标：撤掉端点提示，检验原错误是否消除。前置为本课已学内容，不引入新语法。

题目：输入整数n，输出恰好n行Hello，每行只有Hello，末尾换行，无提示语。输入一行整数；1≤n≤5；C++14标准输入输出。样例输入1，输出一行Hello；样例输入3，输出三行Hello。

样例输入：

```text
3
```

样例输出：

```text
Hello
Hello
Hello
```

提示分级：先问“n=1时应有几行”；仍有困难再让学员列i值。使用任何提示都需记录，不能将该次算独立复验通过。

完整参考程序：

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cout << "Hello\n";
    }
    return 0;
}
```

思路：i取1至n各执行一次；i变为n+1后退出。常见错误为从1开始却排除n。测试覆盖n=1至5，对应1至5行Hello。

## 补练P2：从0开始编号

目标：区分起点变化，防止记成“循环都用小于等于”。前置为已学比较和变量输出。

题目：输入整数n，为n个位置从0开始编号，每行输出一个编号，依次为0至n-1。输入一行整数；输出n行，无提示语；1≤n≤5；C++14标准输入输出。样例输入3，输出三行，依次为0、1、2；样例输入1，输出一行0。

样例输入：

```text
3
```

样例输出：

```text
0
1
2
```

提示分级：先问最后一个合法编号是多少；仍有困难再让学员画出n个位置。记录提示程度。

完整参考程序：

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cout << i << '\n';
    }
    return 0;
}
```

思路：0到n-1共n个数，i等于n时停止。误用 `i<=n` 会多输出编号n。测试n=1至5，分别输出0、0到1、0到2、0到3、0到4，每个数单独一行。

## 补练P3：倒序报数

目标：迁移到递减更新，检验三部分的配合。使用已学减法赋值 `i=i-1`，不要求新记i--。

题目：输入整数n，依次输出n至1，每个数单独一行，不输出0和提示语。输入一行整数；1≤n≤5；C++14标准输入输出。样例输入3，输出三行，依次为3、2、1；样例输入1，输出一行1。

样例输入：

```text
3
```

样例输出：

```text
3
2
1
```

提示分级：先问第一、最后输出值，再让学员预测每次更新后如何接近停止条件。记录是否使用提示。

完整参考程序：

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    for (int i = n; i >= 1; i = i - 1) {
        cout << i << '\n';
    }
    return 0;
}
```

思路：从n递减到1，更新成0后退出。常见错误是更新方向仍加1，或把1排除。测试n=1至5，依次输出1、2到1、3到1、4到1、5到1，各数换行。
