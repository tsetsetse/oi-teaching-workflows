## Global Constraints

- 保留原稿、链接、嵌入、frontmatter 和目标项目教学规范。
- 用户明确要求只读时，不生成任何课程文件。
- 缺关键题面不猜条件；新增或改编题按目标项目规则处理。
- 检查器只对显式指定、已经审阅的程序运行测试，不能将临时工作目录当成隔离环境。
- 私有仓库采用当前目录名 `oi-teaching-workflows`，归属当前已连接的 GitHub 个人账户；若已有同名仓库先核对，不覆盖。

- 未覆盖的代码不能混入“全部通过”；片段与平台程序须说明跳过原因。
