# 教师诊断与下一步教学

## 当前情况与优先级

课程/测次、依据材料、已掌握/提示后完成/待确认、实际评分与缺项；列主要问题的优先级和安排顺序，不用总分替代具体诊断。

## 问题卡：按每个主要问题展开

- **具体表现与证据**：题号、原答/代码、输入或步骤、正确预期与实际结果、证据ID。
- **原因及待确认**：错误机制、已证实的知识关系、需要追问的假设。
- **具体教学改动**：讲解位置、反例/状态表、提示与撤除提示、讲义/演示/课件受影响位置；标明这是下一步计划。
- **补练知识点**：具体关系、条件和常见混淆，哪些已学、哪些需先引入。
- **详细补练题**：练习目标和前置→完整题面/I/O/样例/范围→分层提示→答案与关键思路/完整参考程序→关键测试与预期→常见错法。
- **复验与分支安排**：何时独立完成/解释、达标信号；通过后迁移，未通过时回到哪个环节。尚未复验则保持待验证。

## 下一次安排

优先任务、预计教学顺序/时间依据、学生订正要求、需要补收的证据、后续回读/更新位置。
