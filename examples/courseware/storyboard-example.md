## 教学推进与视觉阶段

本课以同一“输入 n，输出 n 行 Hello”任务贯穿：已有三条输出语句 → 输入次数改变时旧办法不够用 → 找出重复操作与次数 → 用循环表达并追踪 → 回到原题核对输出。它只择取算法推导型中的旧知、抽象与同题验证，不增加第二种算法或性能优化。
学生通过解释“一次输出、一轮循环、n 次重复”的对应和合法边界证明理解；练习与 Bug 修复均围绕原任务。当前均为预期课堂活动，未作为真实课堂观察。

下列“教师备注”均指未来写入对应页的**原生演讲者备注正文**，不是仅附在本计划里。备注含时间、可讲台词、预期回答、误答追问、操作和转场；均为教学预案，不是已发生的课堂记录。所有精确代码、数字和表格用可编辑原生对象；不把整页截图当作课件。

### 第 1 页：一条输出会发生几次？

- 来源/时间/目标：讲义“0～4 分钟”前半；00:00～02:00（2 分钟）；确认顺序执行。
- 投影：课名“01.重复输出”；`cout << "Hello\n";`；问题“一条语句执行一次，输出几行？要三行怎么办？”
- 初始与揭示：先看一条语句，学生回答后下一页呈现三条；本页不先放三行答案。
- 教师备注：“用以前的方法，一条语句能输出几行？”预期“一行”。若说三行，追问“语句执行了几次？”说明 `\n` 换行；请学生口述三条相同语句，再转到固定三行。
- 学生操作/达标：口述；能对应一次执行与一行输出。
- 素材/检查：讲义原有代码片段，无图片附件；字符与换行写法清楚，未引入循环答案。

### 第 2 页：这次 1 行，下次 5 行，次数谁决定？

- 来源/时间/目标：导入后半；02:00～04:00（2 分钟）；分清操作和次数。
- 投影：三条相同输出语句与三行 `Hello`；问题“输入改变，怎样改变执行次数？”；空栏“重复什么：____；重复几次：____”。
- 初始与揭示：学生先说，教师口头归纳；下一页才进入正式任务。
- 教师备注：“固定写三条只能固定输出三行。本题把输入 n 与执行次数连接起来。”预期“输出一行；n 次”；若把 `Hello` 当计数器，追问“内容变了吗，哪一个数决定行数？”转到读题契约。
- 学生操作/达标：指出重复操作和重复次数。
- 素材/检查：沿用讲义情境；三条语句与输出对应，不把范围只有 1～5 说成无需循环。

### 第 3 页：主讲任务——重复问候（题面 1/2）

- 来源/时间/目标：讲义“4～9 分钟”；04:00～06:00（2 分钟）；读清前三字段。
- 投影：来源小字“讲义所载自编测试规格，无外部题号”；**题目描述**“读取整数 n，输出 n 行 `Hello`。”；**输入格式**“一行一个整数 n。”；**输出格式**“共 n 行，每行只有 `Hello`。”
- 初始与揭示：三字段同时完整可读；圈出 n、n 行、每行只有 Hello；不出现解法。
- 教师备注：“输入有几个整数？输出每行允许什么？”预期“一个；只有 Hello”。若回答可带提示语，追问“每行只有是否允许‘请输入 n’？”转到样例和范围。
- 学生操作/达标：圈定三处约束；说出次数来自输入。
- 素材/检查：严格沿用讲义措辞，标题注明 1/2，并与下一页组成完整题面。

### 第 4 页：主讲任务——重复问候（题面 2/2）

- 来源/时间/目标：同上；06:00～09:00（3 分钟）；样例与合法范围。
- 投影：**公开样例**，输入 `3`，输出独立三行 `Hello`；**数据范围、子任务与说明**“1 ≤ n ≤ 5；没有子任务。课堂只使用输入输出和 `for`，不引入数组、函数或其他循环。”；问题“n=1 几行？n=3 几行？”
- 初始与揭示：公开样例完整可见；口头预测 n=1，不显示额外程序。
- 教师备注：“逐行比对大小写、空格和行数，程序不加提示语。”预期“一行、三行”。若把输入值也打印，追问“输出字段要求输出数字吗？”强调 n=0 不是本题合法边界；转到如何从 1 数到 n。
- 学生操作/达标：预测合法输入的行数，读出上下界。
- 素材/检查：样例逐行显示，保留所有题面限制；本页不遗漏“无子任务”。

### 第 5 页：循环的四个部分各管什么？

- 来源/时间/目标：讲义“用计数器控制重复”；09:00～11:00（2 分钟）；建立循环结构。
- 投影：`for (int i = 1; i <= n; i++) {`、缩进的“每次重复的语句”、`}`；用文字标签标出“开始计数（一次）”“先判断”“执行后加一”“每次做什么”。
- 初始与揭示：先问“i 表示什么？”再指对应标签；不放追踪表答案。提示通过标签和边框，不只靠颜色。
- 教师备注：“i 表示准备执行第几次，`<=` 是小于或等于，`i++` 是使 i 加 1。”预期从 1 开始、未超过 n 才执行。若把初始化说成每轮执行，追问“每轮回到 1，还能数到停止吗？”转到手工追踪。
- 学生操作/达标：按顺序指认四部分，不要求其他自增写法。
- 素材/检查：保持原代码语法；这里只解释已有 `main` 外壳之外的新循环。

### 第 6 页：n=3，先填第一次判断

- 来源/时间/目标：讲义 n=3 追踪表；11:00～12:00（1 分钟）；先预测。
- 投影：固定标题“n=3”；表头“准备判断时 i / i<=3 / 本轮操作 / 已输出行数 / 本轮后 i”；四行空格，仅第一行 i=1；标注输出开始前为 0 行。
- 初始与揭示：完整答案保持空白；下一页才揭示第一行。
- 教师备注：“先看判断，再决定是否输出，最后才加一。”等待学生填写首行；预期“成立、输出一行、1、2”。若先加一，追问“循环头的加一发生在输出前还是后？”
- 学生操作/达标：独立口述或在纸上填首行，等待后再翻页。
- 素材/检查：沿用讲义表头；空白真实保留，不在页角提前泄露完整表。

### 第 7 页：i=1，第一行怎样产生？

- 来源/时间/目标：追踪第 1 行；12:00～13:15（1 分 15 秒）；核对第一次。
- 投影：同版表格第一行 `1 / 成立 / 输出 Hello 一行 / 1 / 2`；输出区仅一行 `Hello`；当前代码位置由“判断→输出→加一”标签标识。
- 初始与揭示：只揭示首行；第二行仍空；翻页前预测 i=2。
- 教师备注：“1<=3，所以输出一行，再变成 2。”预期下一轮仍成立；若认为初始化再做一次，回指“一次”标签；转到第二次判断。
- 学生操作/达标：将表内已输出 1 行与输出区对应。
- 素材/检查：代码、i、行数同步；未出现第二、三行输出。

### 第 8 页：i=2，现在累计几行？

- 来源/时间/目标：追踪第 2 行；13:15～14:30（1 分 15 秒）；累计状态。
- 投影：保留首行，新增 `2 / 成立 / 输出 Hello 一行 / 2 / 3`；输出区两行 `Hello`。
- 初始与揭示：首行保持，新增行高亮并有“本轮”文字；第三行仍空，先预测。
- 教师备注：“本轮只输出一行，累计变成两行。”预期下一轮 i=3 仍能执行；若说本轮输出两行，追问“本轮执行几次 cout？”转到等于 n。
- 学生操作/达标：区分“本轮新增 1”与“累计 2”。
- 素材/检查：同一表格位置不跳动；两行输出无多余提示。

### 第 9 页：i=n，还会执行吗？

- 来源/时间/目标：追踪第 3 行；14:30～15:45（1 分 15 秒）；理解包含 n。
- 投影：新增 `3 / 成立 / 输出 Hello 一行 / 3 / 4`；输出区三行 `Hello`；突出 `3 <= 3`。
- 初始与揭示：学生先判断等号，再翻到本页；第四行仍空，问“i=4 会怎样？”
- 教师备注：“小于或等于包含相等，因此第 n 行不会漏。”预期下一次判断失败；误答相等不成立时，让其读出“小于或等于”。转到失败判断。
- 学生操作/达标：能说明第 3 行为何输出。
- 素材/检查：保持先判断后输出；输出区累计三行。

### 第 10 页：i=4，判断失败后还有输出吗？

- 来源/时间/目标：追踪第 4 行；15:45～17:00（1 分 15 秒）；理解停止。
- 投影：新增 `4 / 不成立 / 不进入循环体，结束 / 3 / 不再执行加一`；输出区仍为三行。
- 初始与揭示：先由上一页预测；本页只补停止状态，明确没有第四行输出。
- 教师备注：“这次判断只决定结束。没有进入循环体，也不再执行这一轮加一。”预期判断 4 次、输出 3 次；若说输出第四行，沿标签从条件失败处停止。转到顺序总结。
- 学生操作/达标：解释 i=4 时停止，区分判断和执行。
- 素材/检查：最后一格不能写成 i=5；四次判断不等于四次输出。

### 第 11 页：开始计数做几次？判断与输出各几次？

- 来源/时间/目标：循环追问与板书；17:00～18:00（1 分钟）；串联执行顺序。
- 投影：完整追踪表缩为清晰要点“初始化一次→判断→输出→加一→再判断；不成立则结束”；提问“判断几次？输出几次？”
- 初始与揭示：问题先读，答案由学生口述“4、3”，不预填新的追踪任务。
- 教师备注：预期“初始化只一次；判断四次、输出三次”。若认为每轮初始化，追问“每次都回到 1 会怎样？”短暂停留后转到程序映射。
- 学生操作/达标：全班或点名按顺序说完整，不省略最后失败判断。
- 素材/检查：箭头路径和讲义一致；不引入其他循环。

### 第 12 页：把五步板书放进程序哪里？

- 来源/时间/目标：讲义“从思路到完整程序”；18:00～20:00（2 分钟）；建立模型与代码对应。
- 投影：既有程序外壳内的 `int n;`、`cin >> n;`、循环头与大括号；右侧映射“读次数→从 1 开始→不超过 n→每次输出→加一”。输出位置先留空。
- 初始与揭示：按读入、循环头、大括号的顺序讲；让学生指出输出应放的位置，下一页展示完整程序。
- 教师备注：“先读取 n，再写循环，把重复语句放在大括号里。”预期输出在循环体；若放到括号外，问“这样重复的是哪条语句？”`main` 仅沿用，不讲函数知识；转到完整正确版本。
- 学生操作/达标：指出输入在循环前、输出在循环内。
- 素材/检查：代码仍为原生文本；外壳不被误说成本课新语法。

### 第 13 页：完整正确程序

- 来源/时间/目标：讲义完整代码；20:00～22:00（2 分钟）；形成可抄写核对的程序。
- 投影：下列完整程序原样可编辑显示，不用图片。旁边保留简短“读 n→数 1 到 n→每次一行”。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cout << "Hello\n";
    }
    return 0;
}
```

- 初始与揭示：完整程序在本页一次看全；说明 `\n` 的实际含义，运行输出不含反斜杠和字母 n。
- 教师备注：“每次只输出 Hello 并换行，正式程序没有输入提示。”预期能解释输出语句每执行一次产生一行；若把 `\n` 当输出字面内容，下一页用结果比对澄清。请学生在既有外壳完成程序。
- 学生操作/达标：输入代码并检查分号、大括号和换行。
- 素材/检查：与讲义字符级比对；字号不足时调布局，不缩成难读小字；完整程序仍在最终课件可取得。

- 学生操作/达标：实际输入样例、编译运行并说明差异；未来课堂观察记录与本计划分开。

### 第 15 页：关掉参考，能独立写循环头吗？

- 来源/时间/目标：重写与恰好 n 行解释；25:00～27:00（2 分钟）；从模仿转为回忆。
- 投影：只保留“读 n→从第 1 次数到第 n 次→每次一行→检查下一次”；空白循环头；问题“为什么不漏第 n 行？”
- 初始与揭示：离开完整代码页并关闭其他参考窗口，先独立重写，不在本页暴露答案。
- 教师备注：预期 `for (int i = 1; i <= n; i++)`；理由 i=n 时条件仍成立。需要支架时逐项问起点、条件、加一。口语补充“准备第 i 次时已有 i−1 行，到 n+1 停止”；备忘复杂度 O(n)、额外空间 O(1)，无需让入门学生背术语，也不优化 n≤5。转到同题练习。
- 学生操作/达标：关闭参考后独立写出循环头并解释包含 n。
- 素材/检查：本页不提前显示参考答案；备注保留正确性解释，不替代学生必须看见的代码页。

### 第 19 页：先预测：把条件改成 i<n 会怎样？

- 来源/时间/目标：讲义第一个错例；32:00～33:00（1 分钟）；先找区分输入。
- 投影：明显标注“错误演示片段，不能作参考程序”；`for (int i = 1; i < n; i++)` 与正确的输出行；输入 n=1；空表“首次 i / 1<1 / 输出行数”。
- 初始与揭示：只给错误片段与合法输入，不给输出答案；下一页才揭示。
- 教师备注：“先不运行，第一次判断成立吗？”预期“不成立、0 行”；若说一行，让学生直接判断 `1<1`。不要求运行故意错误程序；转到错误状态与修复。
- 学生操作/达标：先写预测，再解释少一次的原因。
- 素材/检查：沿用讲义错例；明确错误标签，答案不抢先出现。

### 第 20 页：最小修复后，怎样复验？

- 来源/时间/目标：同一错例修复；33:00～34:00（1 分钟）；闭合诊断链。
- 投影：错误状态“n=1：i=1→1<1 不成立→0 行”；最小修复 `<` 改为 `<=`；正确状态“1<=1→输出一行→i=2→2<=1 不成立→停止”；要求“只运行修复后的正确程序，用 n=1、n=5 核对”。
- 初始与揭示：承接学生预测后揭示；“手算预期”与未来实际复验记录分开。
- 教师备注：“原因是漏掉相等，修复要包含第 n 次。”预期 n=1 一行、n=5 五行；若只记符号，让学生解释 i=n。课堂允许时运行正确程序复验，不以本计划当作已运行证据；转到最大合法输入。
- 学生操作/达标：指出最小改动，并说明为什么恢复正确次数。
- 素材/检查：错误片段不混入正确完整参考程序；n=1 状态无多执行一次。

### 第 21 页：n=5 时，i=5 和 i=6 各发生什么？

- 来源/时间/目标：口头提高、边界与按需诊断；34:00～35:00（1 分钟）；迁移停止条件。
- 投影：问题先给，两个状态框留空“i=5：____；i=6：____”；提醒“合法边界：1 和 5”。
- 初始与揭示：学生先说，再由教师口述核对，不提前给满答案。
- 教师备注：预期“i=5 输出第五行，然后变 6；i=6 判断失败，不输出”。其他讲义错例只按实际需要口头诊断：从 0 起仍 `<=n`，n=1 会两行，改起点 1；循环头后多 `;`，n=3 仅一行，删分号；不换行会连成一行，补 `\n`；缺 `i++` 会持续输出，保留加一且不运行此错误。误答多输出时回到失败判断；时间不足压缩本页，不挤占出门测。
- 学生操作/达标：不运行先说出 i=5、6 的行为。
- 素材/检查：备用错例都来自讲义，未新增题；不以 n=0 作通过依据。
