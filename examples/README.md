# 验证案例

`intro-loop/` 是仓库自编的小型测试课程：40分钟，从输入输出过渡到 `for`，只有一道已给出完整条件的“重复问候”任务。
`source.md` 为原稿；`source-讲义版.md` 为实际技能调用产物；`cases.json` 与检查记录用于重跑验证。

验证工作流时，将 `source.md` 和本目录规则复制到临时项目，从不同工作目录调用技能；不要借用评估者先前的结论。

至少检查以下情境：

| 请求 | 应观察到的行为 |
| --- | --- |
| 创建40分钟讲义 | 保留原稿、另存讲义、总课时40分钟；不引入未学语法或新编程题 |
| 只读审阅，展示后再决定 | 仅返回建议，目录文件与内容不变 |
| 缺少关键题面条件 | 明确缺失项，不虚构范围或完整题面 |
| 从现有检查记录续做 | 核对来源变化，只补尚未完成的内容 |

自动测试只覆盖检查工具，不等同于全部情境都经过模型实测。实际执行过哪些行为测试，见 [validation.md](validation.md)。
新增的 [课件交付试做](courseware/README.md)复用同一自编讲义，提供独立生成的分镜计划与PPTX检查工具的验证范围；不包含真实课程成品。
新增的 [竞赛与考试解析试做](exam-analysis/README.md)使用自编混合题型小卷和分层计分编程题，覆盖逐小问、各层完整代码与证据区分；不代表真实考试题量、评分或考纲。
真实课程原稿、题面截图、学生资料和完整成品不进入本仓库；本地试运行证据保存在忽略的 `.local/` 目录。

[作业测评与反馈示例](practice-feedback/README.md)使用完全自编的任务、合成作答和提示记录，演示错误复现、详细教师补练与鼓励型家长草稿；不包含真实学生记录。
