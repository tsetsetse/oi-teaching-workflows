## 练习：重复问候

**题目描述**

读取整数 n，输出 n 行 `Hello`。

**输入格式**

一行一个整数 n。

**输出格式**

共 n 行，每行只有 `Hello`。

**公开样例**

样例输入 1：

```plain
3
```

样例输出 1：

```plain
Hello
Hello
Hello
```

**数据范围、子任务与说明**

1 ≤ n ≤ 5；没有子任务。课堂只使用输入输出和 `for`，不引入数组、函数或其他循环。
