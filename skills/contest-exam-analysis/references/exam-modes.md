# 考试模式与逐题解析

只读取本次模式需要的部分。题目身份、题型、题量、分值、选项、程序语言与小问结构均以指定原卷为准；不把某年模板变成所有年份的规则。

## 单题 single

锁定题号、原始链接或原卷位置、完整题面与 I/O。编程题按 [编程与分层要求](programming-and-scores.md) 完成推理、不同视角、完整实现和核验；局部追问按用户范围，不为补齐模板重写全部。单个选择、判断、程序阅读或填空题按下方相应题型处理。

## GESP 整卷 gesp

锁定年月、语言、一级至八级中的具体等级及原卷版本；不把相邻等级或其他语言的卷子混入。结合学生等级解释概念和语法，必要时补前置说明；考点归类读取适用版本的官方大纲，已有 `gesp-solver` 随附摘要不能直接当作当次官方标准。

使用可用的 `gesp-solver` 保留逐选项分析、代码追踪、考点归纳的长处；其固定题量/分值、简述编程题、保存位置和代码风格按本次原卷及项目要求调整。输出仍由主工作流统一覆盖、完整题面、分层程序和验证，不能仅拼接答案。

## CSP 初赛 csp-first

锁定年份、J/S、第一轮原卷、适用语言约定和完整题号结构。先列原卷章节，再列所有实际小问与程序空；解析文档可共享题干，但核验清单使用叶子题号，例如 `阅读2-问3`、`完善1-空2`。保持原卷编号，内部唯一标识与原号之间有映射。

程序阅读题说明整体功能、变量语义、关键状态、循环/递归顺序、边界和每问推导；代码与配图、表格、输入不能脱离原题。完善程序题逐空说明位置、约束、备选项为何适用或不适用；还原完整程序后检查整体正确性，不把各空孤立看待。运行脚手架与原卷代码分开记录。

## CSP 复赛 csp-second

锁定年份、J/S、第二轮原卷、每题文件名与 I/O 方式、时空限制、特殊性质、子任务/测试点和评分规则；有数据附件时核对对应题名、点号及输入输出。每题采用完整编程题解析，给出不同视角与有意义的部分分实现，再给可处理全部范围的方案。

每个分层方案按原题实际条件解释可覆盖的分数，提供完整程序与独立测试。数据未提供或测试组分值未知时只写论证的范围与未知项，不估造正式得分。原题的特殊判定、多解、浮点容差或文件读写须保留，不能用简单字符串比较替代其判定规则。

## 题型共同要求

| 题型 | 必需内容 | 核验重点 |
| --- | --- | --- |
| 选择 | 题干、全部实际选项、答案、每项对错理由、考点；必要执行追踪 | 逐项成立条件、错误原因，不能只排除另外几项 |
| 判断 | 原命题、答案、条件与依据；错误时给反例或正确表述 | 全称/存在量词、边界、术语与语义 |
| 阅读程序 | 共享完整代码、输入、状态追踪、每个小问的答案与理由 | 执行次数/判断次数、下标、递归返回、类型与输出格式 |
| 完善程序 | 共享代码、逐空目标、候选分析、完整还原程序 | 填空组合后的整体行为；合法替代写法按题目要求判定 |
| 编程 | 完整题面、手算/建模、多视角与分层推导、证明、复杂度、每层完整实现、验证 | 每层适用范围、得分依据、I/O、边界、整数上界 |

先分析代码是否具有明确语义；未定义/实现相关行为、环境或版本差异单列，不能用某次运行输出证明唯一标准答案。原卷/官方答案冲突时分别引用证据并列出疑点，不偷偷改原题。
