# 阶段课程规划与学习路径

把目标、材料、前置知识、时间和学习证据组织成可执行、可检查、可调整的阶段计划。先确定本次产物，再选择规划依据；成熟课程直接复用并映射，不要求每次重新设计全部内容。

## 1. 锁定范围与两层产物

读取目标项目适用的 `AGENTS.md`、指定教材/讲义/课程目录、已有计划与记录、目标和可用课时。保留原稿、创建时间、内容链接和历史记录；只读讨论/审阅只在对话中交付，创建或修改仅写本次获准产物。使用当前课程项目的目录与命名，没有约定时在本次规划目录保存；技能资源相对自身目录定位。

按 [产物层次与四类路径](references/layers-and-modes.md) 确定：

| 本次产物 | 输入与交付 |
| --- | --- |
| 标准课程路径/讲义母版 | 面向目标群体，提取或构建章节、知识关系、核心/拓展、课时区间、任务和达标要求。无需具体学员数据；课程前置假设不当作某个孩子的实际掌握 |
| 学生/班级阶段实施计划 | 在母版与本次约束上选定课次、时长、起点、逐课任务、检查和调整分支；有证据的基础与待确认内容分别记录 |

已有成熟多章讲义可以同时提供母版与详细内容，保留其结构和来源映射；不是必须先改成另一份大讲义。只有用户要求完整新写/改写讲义时，才交接备课流程制作内容。用户仅要家长规划说明时，按已知目标/观察写未来安排，不强制出课表或完整讲义。

## 2. 确认依据、起点与目标

选择已有课程安排、目标倒推、薄弱补强或项目驱动，允许有明确分工的组合。记录目标群体/匿名学员、来源版本、语言环境、已有课程、目标、时间和约束；沿用已经确认的信息，仅问影响规划的关键缺项。

将“学会某知识”拆成可观察行为与证据。区分已授课、独立完成、提示后完成、订正通过、待复验、未测；教师观察也可作为它支持的依据，不强制要求代码文件。未测不当作不会或已会，母版假设与未来计划不升级为个人学习事实。

缺具体学情时可形成条件性实施草案，并把必要诊断计入时间；标准母版不因无学员数据而受阻。没有日期则使用课次，不编造上课日期、节假日或日历。要求考试/竞赛对齐时锁定适用身份与版本并核对官方来源；未核实只做通用路径及待核对项，不保证覆盖所有试题或固定通过率。

## 3. 建立路径、任务与容量

使用 [标准课程模板](assets/course-blueprint-template.md) 或 [阶段计划模板](assets/stage-plan-template.md)。把来源章节/题目/作品映射到知识单元、前置、主要任务、达标证据和核心/拓展；说明安排理由。区分教材先后与必需先修，保留可以并行或调整的分支，不把示意路线变成所有学生的唯一顺序。

按 [容量核算与调整](references/capacity-and-adjustment.md) 选择本次核心范围，计算章节课次区间、实际逐课活动和总时间；课外作业与课堂分别记。每课预算包含实际需要的回顾、讲解/手算、独立练习、检查和记录，不叠加重复模板，不靠默删测评或把拓展当必会来凑时间。

逐课卡写清：目标与前置依据→核心任务/知识关系→分段时间→练习和家庭巩固目标→预期成果→达标检查与未达标分支→需要准备的讲义/程序/演示/课件。仅规划时任务要具体，但不默认生成全部题目、代码、PPT或网页。

时间或目标冲突时列出缺口和可选择的缩范围、后延或延课方案；不得擅自改变明确的总课次、截止时间或核心目标。用户已允许的取舍直接执行并记录；尚未选择时保留可用部分和条件，不宣称无条件可完成。

## 4. 设置检查、补强与阶段分支

把目标对应到可执行的检查任务、独立/提示程度和达标依据，按知识衔接安排复习、迁移和测评，不统一规定某分数或刷题量等于掌握。未来进入条件标为待验证；资料齐全或程序生成不等于学习达标。

关键前置不足时补对应知识并重算受影响课次；局部边界错误可定向复验，不自动冻结全部路线。稳定独立表现支持减少重复、进入迁移；证据不足先收集证据，不贴能力或态度标签。班级先给共同主线，再按需要补强/拓展；不默认为每人创建一套全新课程。

## 5. 交接与续做

按 [交接与验收](references/handoffs-and-verification.md) 将具体课次卡交给 `lesson-preparation`；确定讲义后按需要进入 `courseware-delivery`。测评蓝图、学习证据和检查节点交 `practice-assessment-feedback`；选定题目/试卷的详细解析交 `contest-exam-analysis`。通过环境或同级目录读取对应技能；规划任务本身不自动启动其他产物。

收到新学情、时间或来源变化时，使用 [进度与调整模板](assets/progress-adjustment-template.md)，先保留已完成课次的原计划与实际记录，再计算已用、剩余和总时间，只调整获准的未来/受影响部分。后延目标保持可见，不改名为完成；原始作答、旧结论和原计划可追溯。需要改变既定目标或期限时给出具体取舍，已确认的选择不重复请求。

家长规划说明按需生成，用通俗未来时态解释目标、理由和配合；个人现状只引用实际证据。阶段进步与实际反馈交已有反馈流程，不能把预期成果当已经发生；仅交草稿，不发送。

## 6. 核验与交付

使用 [验收模板](assets/verification-template.md)，核对来源映射、前置关系、目标覆盖、核心/拓展、单课与阶段预算、达标证据、调整影响及授权范围；分别记录资料/结构检查、人工判断和实际教学尚未验证项。若额外运行程序，先审阅并提供显式测试清单。

交付本次要求的母版、阶段总表/逐课卡、测评与补强分支、进度/调整记录及按需家长说明。前置或时间尚未确认时保留条件性状态；规划合理不等于教学有效。真实课程和学生资料留在使用者项目，源码示例使用自编材料；安装、GitHub同步、日历和定时任务按相应明确授权另行执行。
