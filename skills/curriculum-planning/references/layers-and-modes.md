# 产物层次与四类路径

## 标准层与实施层

标准层面向目标群体，说明适用基础、知识路径、来源映射、核心/拓展、章节课时区间、任务与达标要求。无需某个学生的作答；前置写成课程假设/进入要求，不能把它变成所有学员已达成事实。已有多章讲义若已包含这些结构，应提取、核对并复用，不重复创建同义课程。

实施层面向本次学生/班级和约束，从标准范围选择实际目标与课次。基础状态逐项引用课堂观察、作答或测评，保留提示程度和待测项。缺学情时安排必要诊断并给条件性草案，不强行判定学生不会；只缺日期不妨碍按课次排计划。

同一材料可以同时承载标准路径与详细讲义。规划可指出需补的检查/课次安排；未获准时不改原讲义，也不以标准路径文件缺少个人记录为缺陷。用户要求完整新建课程母版时，先明确范围并形成内容组织，再按授权衔接备课/课件等制作。

## 四类路径依据

| 路径 | 输入与主要判断 | 应交付的规划依据 |
| --- | --- | --- |
| 已有课程安排 | 教材目录、成熟讲义、已授进度与本次课时 | 保留结构与内容来源，明确重排、合并、后延和原因 |
| 目标倒推 | 明确能力/考试/竞赛目标、当前基础、时间与适用官方来源 | 从可观察能力反推必要知识与检查，标出时间/覆盖冲突 |
| 薄弱补强 | 具体错因、提示程度、订正和独立复验记录 | 只回到受影响的前置，安排原错、边界和迁移检查 |
| 项目驱动 | 作品要求、学生基础、平台与可用时间 | 将功能拆成递进任务，解释知识如何服务功能与验收 |

材料没有覆盖的内容标为新增建议，不借来源标题、考试名称或课程编号推断其全部范围。跨语言或平台迁移保留运行环境与前提，Python图形任务不强套标准输出。

## 输出规模

默认聚焦本次阶段，不自行扩成全年体系、全套课件或管理系统。每个逐课任务应具体到能交接制作，例如“比较两种起点的循环次数并独立解释停止值”，不只写知识名称；完整题面、程序和详细讲稿由对应制作阶段落实。

家长只要未来规划时，用现有目标、已知观察和安排理由形成说明；不要附加学习成绩、虚构历史进步，或强制补完整题库/测评材料。
