# 步骤设计与检查

用于新算法或状态机制的较大变更。只读当前主题有关的部分；无需把这里所有内容都放进学生页面。

## 步骤最少保存什么

每一步通常包含：

- **动作**：当前做了什么，关联哪条代码语句。
- **数据状态**：数组、网格、队列、栈、区间、距离或其他未来步骤所依赖的值。
- **执行位置**：循环下标、当前节点、搜索方向、递归帧、正在比较的两个元素等。
- **已揭示结果**：这一刻已经产生的输出，不是整个运行最终会得到的输出。
- **解释**：为什么合法、为什么更新或为什么跳过；必要时附下一步预测问题。

例如同一条查询语句可以对应“选取两个前缀 → 抵消重叠部分 → 揭示差值”三个教学步骤，各步仍指向同一语句。代码若只是局部片段，应标明“核心代码”；标为完整程序时应可独立运行。

不必模拟每条无关的输入输出指令，但不能省略会改变算法语义的分支或状态。未计算、不存在、不可达和数值 0 是不同状态，显示方式应有所区别。

快照可以只保存会变化的部分，常量放在模型中。大范围枚举会产生过多步骤时，按实际教学需要限制输入或步数，并说明限制；不要让浏览器因完整保存巨大轨迹而失去响应。

## 按算法选择观察对象

| 算法 | 必须说清的状态或约定 | 合适的演示动作 | 容易讲错或画错的地方 |
| --- | --- | --- | --- |
| 前缀和 | `s[i]` 的含义、下标起点、空前缀 | 加入一项、选择两个前缀、抵消、求差 | `l-1` 与 `l` 混淆；负数时前缀和未必递增 |
| 二分 / 二分答案 | 搜索对象、可行性方向、闭区间或半开区间、不变量 | 取中点、算判定、保留一侧、终止 | 混用两种区间模板；丢失答案；示意锯片高度和实际 `mid` 不一致 |
| DFS 连通块 | 统计对象、邻接方向、扫描顺序、访问含义、调用栈 | 找新起点、进入并标记、检查邻居、跳过、返回 | 把对角线算相邻；返回时撤销本应永久保留的访问标记 |
| DFS 路径枚举 | 当前路径、分支合法性、路径内判重、回溯恢复 | 选择、加入路径、递归、撤销选择 | 照抄连通块的永久标记，使其他合法路径被漏掉 |
| BFS | 起点、距离/层次、判重键、队列头尾 | 入队并判重、出队、扩展邻居 | 出队才判重造成重复入队；把访问顺序画成最短路径 |
| 排序 | 比较关系、已确定区间、稳定性要求 | 比较、交换/移动、更新边界 | 每次比较都画成交换；动画顺序与代码循环顺序不同 |
| 动态规划 | 状态语义、初始值、不可达值、依赖顺序 | 查看依赖、比较候选、更新状态 | 用 0 代替不可达；读取尚未计算的格子；更新和取答案混在一起 |

对于连通块，如果只说 `W` 是水、`.` 是陆地而没有说明统计哪个对象，应先确认；对于“水域连通块”则已明确，无需重问。四方向地图 `W.W / .W. / W.W` 的水域块数为 5；可用来发现误用八方向的问题。

## 让学生能解释变化

先提供需要回答的具体问题，再揭示关键更新。例如：

- 前缀和：`s[r]` 多包含了哪些元素？为什么要减去 `s[l-1]`？
- 二分：这次判定排除了哪一侧？为什么那一侧都不可能更好？
- DFS：这个格子为什么能进入？为什么递归返回后不能重新算一块？

问题应能由当前状态回答，不要求学生猜尚未呈现的变量含义。完整讲义另有要求时再展开教学目标、练习等内容；一个交互演示无需硬套整课结构。

## 有效的验证

### 算法与快照

选取手算案例和能区分常见错误的反例。对状态快照，至少比较同一步在“首次前进”和“走远后回退”时的数据；不能只比较最终答案。

| 主题 | 有区分力的检查 |
| --- | --- |
| 前缀和 | `l=1`、`l=r`、全区间、负数、零；用直接逐项累加对照 |
| 二分 | 答案位于两端、区间只剩一个候选、全部/没有可行值（按题意定义） |
| 连通块 | 单格、全背景、全目标、仅对角相邻、多个分离块；用不同遍历实现计数对照 |
| 排序 | 已有序、逆序、重复值、单元素；比较排序结果并检查元素未丢失 |
| DP | 基础状态、无解/不可达、小范围枚举对照 |

### 修改已有演示

扩大输入上限时，从输入端追踪到最终参考程序。例如把前缀和长度从 16 改为 24，使用 `1…n` 下标的固定数组至少需要 25 个位置，同时重算整数溢出与画面/步数限制。断言应验证边界处的实际结果和越界输入处理，而不是只检查源文件出现了“24”。

修改计时或播放方式时，验证快速切换不会遗留多个定时器；修改视图切换时，检查隐藏代码面板期间推进步骤、重新显示后高亮行仍可见。快捷键要同时在页面和输入框中检查，避免把输入中的空格或方向键当作播放操作。

视图恢复的回归操作：先跳到末尾，再只看动画、重置、恢复代码＋动画，初始化高亮行应完整处于代码面板内；随后检查隐藏期间推进与跳转后恢复视图。用代码行与滚动面板的实际边界判断可见性，并记录宽窄屏的实际尺寸，不能只检查高亮样式是否存在。

### 交付记录

记录“使用哪个浏览器、实际检查哪些操作、是否直接打开离线文件”。编译、纯算法自检、页面渲染和真实交互分别提供不同证据；不以其中一种替代其他检查。只有实际执行过的内容才能写为已验证。
