# 阶段课程规划自编示例

全部课程、班级和学习记录均为自编/合成材料。用户提供的成熟讲义只用于只读参考，没有被复制或修改。

- 原始输入：[course-source.md](course-source.md)、[learner-constraints.md](learner-constraints.md)、[update-record.md](update-record.md)。
- 标准层：[course-blueprint.md](course-blueprint.md)。不依赖个体学情，保留四单元及核心/拓展、先修与课时范围，识别110分钟模板。
- 实施层：[stage-plan.md](stage-plan.md)。六次90分钟=540分钟，个人证据与未来条件分开，具体任务交接到制作阶段。
- 续做：[adjusted-plan.md](adjusted-plan.md)。保留两次实际180分钟，未来四次360分钟；按新增授权后延综合，未完成不写达标。
- [验证记录](verification.md)区分数值/结构检查、独立执行、人工审查和真实教学未验证。

检查场景：标准母版没有学员数据；成熟课程不重写；110分钟素材到90分钟实施；已授不等于独立掌握；知识依赖不等于教材顺序；目标与时间冲突；缺官方身份；仅家长未来安排；续做保留历史；仅规划不制作完整讲义/PPT。

前向评估时只读取三份原始输入和技能，在独立临时项目生成结果，不借用本目录三份产物作为答案。规划不执行课程程序或创建日历。
