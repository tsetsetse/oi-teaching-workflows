# v0.4.0 统一入口验证记录

## 实施范围

新增 `teaching-workflows`，与三个专门工作流及四个完整能力模块组成八模块套件。统一入口负责范围、分派、交接与续做，不新建调度服务、全局会话钩子或自制安装器。README复用官方skill-installer并采用固定标签、空目录暂存、备份与完整目录替换的步骤。

## 行为基线

独立只读评估了五类请求：只读备课、题解转PPT、来源变化后的续做、只改交互输入、正式CSP原卷解析。原有模块已具备各自边界，但没有 `$teaching-workflows` 定义，跨阶段记录与直达能力模块缺少统一约定。新增入口只补这些组织规则，不重复专门工作流。

## 边界

情景评估不等于桌面技能发现或完整课件交付。个人目录暂存试装不改变正式安装；本次不修改现有个人技能、教学项目规则或课程成品。portable插件宿主、真实浏览器、真实课堂与完整官方考试试卷的端到端运行仍需分别验证。
