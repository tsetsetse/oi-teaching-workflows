# 探测器充能助手：while怎样让作品继续运行

自编教师小课例。前置、正式任务与许可见source.md；总时间见project-design.md。核心是“检查条件→执行→更新→回到检查”，变量、赋值、比较和输入均为已学。

## 0—10分钟：先看到目标

教师展示目标为3时逐轮报告1、2、3及完成。问：“目标换了，重复次数还相同吗？达到目标后还要继续充吗？”先收集猜测，不展示循环代码。用旧输出和一次更新确认必要前置；角色外观不计为语法能力。

## 10—22分钟：用旧知识做一个小部分

V1只观察初值：

```python
target = 3
energy = 0
print(energy)
```

V2只充一次：

```python
target = 3
energy = 0
energy = energy + 1
print(energy)
```

依次输出0、1。让学生解释右侧读取0，加1后写回energy。教师问：“现在达到目标3了吗？还需要什么？”预期：还需继续充能。两段都是观察程序，进入正式任务时不保留初值输出。

## 22—35分钟：从动作得到重复规则

把状态卡从0逐次换到1、2、3，每次动作前先问“当前能量还小于目标吗”。让学生尝试复制更新与输出，再追问目标变化后如何知道要复制几次。

| 检查前能量 | 目标 | energy小于target吗 | 本轮动作 | 输出 |
| --- | --- | --- | --- | --- |
| 0 | 3 | 是 | 加1写回，变1 | 1 |
| 1 | 3 | 是 | 加1写回，变2 | 2 |
| 2 | 3 | 是 | 加1写回，变3 | 3 |
| 3 | 3 | 否 | 停止充能 | 不产生本轮数字 |

学生先口述：“只要还没达到目标，就充一次，再回来检查。”教师此时引出while，而后对应条件、缩进内的动作和返回检查。目标0时第一次检查即为假，一轮都不执行。

## 35—50分钟：主任务与模型到代码

本题为自编题，条件已在source.md给定。

**题目描述**

探测器初始能量为0。读入目标能量N，每次充能使能量增加1。只要尚未达到目标就继续充能，每次充能后报告当前能量；达到目标后输出“完成”。

**输入格式**

一行，一个整数N。

**输出格式**

每次充能后输出当前能量，每个整数占一行；最后一行输出中文“完成”。不输出初始能量、输入提示或额外空行。N=0时只输出“完成”。

**公开样例**

样例输入1：

```plain
3
```

样例输出1：

```plain
1
2
3
完成
```

样例输入2：

```plain
0
```

样例输出2：

```plain
完成
```

**数据范围、子任务与说明**

0<=N<=20，保证输入为合法整数；使用while组织重复。每轮是一次充能操作，不表示真实时间，不调用等待函数。无考试评分子任务。

**教师讲稿**：“刚才我们每次先检查，再充能，再报告。把需要重复的动作缩进到while里。完成的提示在循环结束以后执行。”让学生指认条件、更新与输出位置，再对照状态表，参考程序在独立任务后折叠展示。

## 50—63分钟：实现与排错

学生完成V3并用目标3、0、1预测后运行。问：“为什么每轮都要更新？完成提示属于重复动作吗？”

展示故意错误片段，只纸面追踪三轮，不实际执行：

```plain
target = 3
energy = 0
while energy < target:
    energy + 1
    print(energy)
```

> [!example]- Bug分析（点击展开）
> 每次虽然计算0+1，但没有写回energy，状态仍为0，条件一直成立，会持续输出0。最小修复为把计算结果赋给energy；再追踪0→1→2→3，第四次检查停止。目标0时错误版本也会零次执行，因此只测0发现不了这个Bug。

| 检查前能量 | 是否进入 | 更新后能量 | 本轮输出 |
| --- | --- | --- | --- |
|  |  |  |  |

> [!example]- 主任务完整参考程序（点击展开）
> ```python
> target = int(input())
> energy = 0
> while energy < target:
>     energy = energy + 1
>     print(energy)
> print("完成")
> ```
>
> 每次从小于目标的整数增加1，不会跳过目标；到达目标后条件为假，因此恰好报告1到N，并输出完成。这里的解释用于基础课，不要求孩子背术语。

## 78—86分钟：迁移到氧气消耗

不提供主任务方法名或循环模板，让学生自己确定条件和每轮变化。题面中的动作次数由初始氧气决定，需重新建立“减少到0”的过程。

**题目描述**

探测器有M格氧气。每次行动消耗1格氧气，消耗后报告剩余格数。氧气变为0时停止行动，最后输出“结束”。

**输入格式**

一行，一个整数M。

**输出格式**

每次行动后输出剩余氧气，每个整数占一行；最后一行输出中文“结束”。不输出初始氧气或提示文字。M=0时只输出“结束”。

**公开样例**

样例输入1：

```plain
3
```

样例输出1：

```plain
2
1
0
结束
```

**数据范围、子任务与说明**

0<=M<=20，保证输入合法，无考试评分子任务。先填写状态再运行，说明什么时候继续、每轮改变什么以及如何停止。

> [!example]- 参考答案（点击展开）
> ```python
> oxygen = int(input())
> while oxygen > 0:
>     oxygen = oxygen - 1
>     print(oxygen)
> print("结束")
> ```
>
> M=3时状态3→2→1→0；每轮减1，到0停止。与充能相同的是先检查、动作后更新再检查，变化方向和继续条件不同。
