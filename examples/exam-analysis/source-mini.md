# 自编混合题型小卷

仅用于验证整卷覆盖与解析机制，不是 GESP 或 CSP 真题，不代表真实题量、分值或等级考纲。共六个需要单独解析的题号/小问/空：1、2、3.1、3.2、4.1、4.2。

## 1. 选择题

下面程序片段输出什么？变量为普通 C++ 整数，初始值如下。

```cpp
int s = 0;
for (int i = 1; i <= 3; i++) s += i;
cout << s;
```

A. 3　B. 5　C. 6　D. 7

## 2. 判断题

在 C++ 中，`i <= n` 中的 `<=` 是赋值运算符。

## 3. 阅读程序

```cpp
int s = 0;
for (int i = 1; i <= 3; i++) s += i;
cout << s;
```

- 3.1：循环体执行几次？
- 3.2：循环条件 `i <= 3` 总共判断几次？包括最后一次不成立的判断。

## 4. 完善程序

程序读取整数 n（1 <= n <= 100），输出 1 到 n 的和，输出后换行。

```cpp
int n, s = 0;
cin >> n;
for (int i = /* 4.1 */; i <= n; i++) {
    s += /* 4.2 */;
}
cout << s << '\n';
```

分别填写 4.1 与 4.2，并解释依据。
