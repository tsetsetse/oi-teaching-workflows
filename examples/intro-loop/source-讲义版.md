# 01.重复输出（讲义版）

本文件是工作流测试夹具，题面为仓库自编测试规格，不是真实学生资料。
相邻课程：[[00.输入输出]]。原稿：`source.md`；本课依据原稿整理，原稿保留。

## 教学目标与前置知识

- 学生已学：变量、`cin`、`cout`、顺序执行。
- 本课新学：`for` 循环；在循环中初次认识 `<=`（小于或等于）和 `i++`（使 i 加 1）。不要求学生先掌握其他循环。
- 课末表现：能说清“开始计数—判断—执行—加一—再判断”的顺序；能对 n=3 手工跟踪；能独立完成同一题，在合法范围内输出恰好 n 行。
- 重点：让循环次数与题目要求一致。难点：每轮先判断、执行后加一；最后一次不满足条件时不会输出。
- 语法边界：课堂只使用输入输出和 `for`，不引入数组、函数或其他循环。完整程序中的 `main` 沿用既有程序外壳，不作为函数知识讲授。
- 时长：40 分钟。教师提前准备空白程序外壳和下方追踪表，学生使用可编译 C++14 的环境。

## 板书主线与课时安排

板书主线：读 n → 从第 1 次数到第 n 次 → 每次输出一行 → 检查下一次是否还能执行。

| 时间 | 教师主线 | 学生活动 | 当场检查 |
| --- | --- | --- | --- |
| 0～4 分钟（4 分钟） | 从顺序输出提出重复问题 | 口述输出三行的旧办法 | 知道一条 `cout` 执行一次 |
| 4～9 分钟（5 分钟） | 读题、锁定输入输出 | 圈出 n、n 行、每行只有 Hello | 能预测 n=1 和 n=3 的输出 |
| 9～18 分钟（9 分钟） | 引入 `for`，手工追踪 | 跟踪 n=3 的每次判断 | 能解释 i=4 时为什么停止 |
| 18～27 分钟（9 分钟） | 映射到完整程序并运行 | 输入公开样例，逐字符比对输出 | 输出三行，无提示语和多余空行 |
| 27～35 分钟（8 分钟） | 同题练习、边界和易错诊断 | 分层完成同一程序并检查 n=1、n=5 | 循环次数正确，能说明错因 |
| 35～40 分钟（5 分钟） | 出门测与小结 | 独立写循环、口述执行顺序 | 达到课末可观察目标 |

合计：4+5+9+9+8+5=40 分钟。进度慢时优先保证独立写出循环和 n=1 的检查，拓展口头讨论课后进行。

## 逐段讲稿

### 0～4 分钟：从顺序执行引出重复

教师说：“要输出三行 Hello，按以前的方法，一条语句能输出几行？”

学生预期回答：“`cout << "Hello\n";` 执行一次输出一行，写三次就输出三行。”请学生口述三条相同语句，不另布置新题。

教师追问：“如果这次输入 1，下次输入 5，程序怎样知道应该执行几次？”

预期回答：“次数由输入的 n 决定。”教师归纳：逐条抄写能完成固定三行，但条数写死；本题要让相同操作重复 n 次。即使范围只有 1～5，仍需把输入的次数与执行次数连接起来，今天用 `for` 完成。

检查点：请一名学生指出“重复的操作”是输出一行，“重复次数”是 n。不要把重复输出的内容写成计数器。

### 4～9 分钟：主讲任务——重复问候

来源：同目录原稿 `source.md` 中的自编测试规格；无外部题号。以下五个加粗字段、条件与公开样例沿用原稿。

**题目描述**

读取整数 n，输出 n 行 `Hello`。

**输入格式**

一行一个整数 n。

**输出格式**

共 n 行，每行只有 `Hello`。

**公开样例**

样例输入 1：

```plain
3
```

样例输出 1：

```plain
Hello
Hello
Hello
```

**数据范围、子任务与说明**

1 ≤ n ≤ 5；没有子任务。课堂只使用输入输出和 `for`，不引入数组、函数或其他循环。

教师引导学生圈出契约：输入只有一个整数；输出行数由它决定；内容大小写固定；行内无额外空格。正式程序不输出“请输入 n”等提示。

口头检查：n=1 时有几行？预期回答“一行”；n=3 时有几行？预期回答“三行”。n 的合法范围已经保证，不增加无关的输入校验分支。

### 9～18 分钟：用计数器控制重复

先给循环结构：`for (int i = 1; i <= n; i++)`，大括号内放每次重复的语句。

- `int i = 1`：开始时令 i 为 1，只做一次。i 表示“准备执行第几次”。
- `i <= n`：每轮开始前判断；`<=` 表示“小于或等于”。满足条件才进入大括号。
- 循环体：执行输出一行的操作。
- `i++`：本轮执行后 i 加 1，再回到条件判断。这里不讲其他自增写法。

教师先遮住程序，带学生对 n=3 画出下表；学生说出每格内容，教师再揭示。

| 准备判断时的 i | `i <= 3` | 本轮操作 | 已输出行数 | 本轮后 i |
| --- | --- | --- | --- | --- |
| 1 | 成立 | 输出 Hello 一行 | 1 | 2 |
| 2 | 成立 | 输出 Hello 一行 | 2 | 3 |
| 3 | 成立 | 输出 Hello 一行 | 3 | 4 |
| 4 | 不成立 | 不进入循环体，结束 | 3 | 不再执行加一 |

教师追问：“判断做了几次？输出做了几次？”预期回答：“判断四次，输出三次。最后一次判断只决定停止。”

再追问：“`int i = 1` 会不会每轮重新执行？”预期回答：“不会，开始时执行一次，否则 i 总回到 1，就数不完了。”

板书顺序：初始化一次 → 判断 → 输出 → 加一 → 判断…… → 条件不成立时结束。

### 18～27 分钟：从思路到完整程序

映射关系：`cin >> n` 读取次数；i 从 1 开始；只要 i 不超过 n 就输出一行；每轮后 i 加一。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cout << "Hello\n";
    }
    return 0;
}
```

教师操作：先读入 n，再逐部分写循环；写完大括号后把输出语句放进去。说明 `\n` 表示换行，运行结果不会出现反斜杠或字母 n。

学生操作：输入公开样例 3，编译运行，逐行与题面样例比对；确认只有三行 Hello，大小写一致。随后关闭参考程序，凭板书重写循环头。

教师提问：“为什么不会漏掉第 n 行？”预期回答：“i 等于 n 时，`i <= n` 仍成立。”

教师备课说明（可用口语讲述，不要求记术语）：开始输出前为 0 行；准备第 i 次输出时，已经完成 i−1 行。只要 i≤n，就再输出一行，随后 i 加 1。i 从 1 依次到 n，每个数对应一行；到 n+1 时停止，所以恰好输出 n 行，而且每行由同一条语句保证内容为 Hello。

复杂度：输出 n 行必需做 n 次输出，时间复杂度 O(n)；只保存 n 和 i，额外空间 O(1)。本题 n≤5，不需要优化；用循环的目的在于表达输入决定的重复次数。

### 27～35 分钟：同题分层练习与易错诊断

本节不新增编程题；所有编程练习都完成上方“重复问候”的同一契约。

| 层次 | 学生操作 | 教师预期与检查 |
| --- | --- | --- |
| 基础 | 在已给输入语句与输出语句的程序中，补全循环头和大括号 | 应得到 `for (int i = 1; i <= n; i++)`，输出语句在大括号内 |
| 达标 | 关闭参考程序，从既有程序外壳独立写出同题完整程序 | 输入 n=1、n=5，分别只有 1、5 行 Hello；没有提示语 |
| 提高（口头） | 不运行，说明 n=5 时 i=5 与 i=6 各发生什么 | i=5 输出第五行，随后变 6；i=6 判断失败，不输出 |

教师按需要选下列一个错例追问，不要求学生运行故意错误的程序。

| 局部错误 | 用合法输入手算的结果 | 修正与原因 |
| --- | --- | --- |
| 把条件写成 `i < n`，仍从 1 开始 | n=1 时第一次判断就失败，输出 0 行 | 改回 `i <= n`，包含第 n 次 |
| 从 `int i = 0` 开始，仍判断 `i <= n` | n=1 时 i=0、1 各执行一次，输出 2 行 | 保持本课从 1 数到 n，起点改回 1 |
| 在循环头右括号后多写 `;` | 循环体变成空语句；后面的大括号只执行一次，n=3 时仅 1 行 | 删除这个分号，让大括号成为循环体 |
| 输出写成 `Hello` 后不换行 | n=3 时三个 Hello 连在一行 | 每次输出末尾加 `\n` |
| 忘记执行后加一 | 对合法 n，i 一直为 1，持续输出，不能正常结束 | 保留 `i++`，每轮向停止条件前进一步 |

教师提醒：不要用 n=0 证明正式程序“通过边界”；本题的最小合法输入是 1，最大是 5。诊断时先预测，再运行正确程序核对，避免让无限输出干扰课堂。

### 35～40 分钟：出门测与小结

出门测在纸上完成，不增加新编程题：

1. 写出本题循环头。预期：`for (int i = 1; i <= n; i++)`。
2. 按顺序口述执行过程。预期：初始化一次、先判断、成立则输出、加一、再判断；不成立则结束。
3. 当 n=1 时，首次输出前 i 为多少？下一次判断时 i 为多少，是否输出？预期：1；2；不输出。

评价：三项都独立完成为达标；循环头正确但顺序说不清时，课后用 n=1 重做状态追踪；暂未独立写出时，沿着五步板书逐项补全，不加新语法。

板书收束：重复什么？输出一行。重复几次？输入的 n 次。怎样防止多一次、少一次？从 1 开始，包含 n，每轮加一，并检查最小合法输入。

## 作业（同题巩固）

在不看参考程序的情况下重写本课“重复问候”；题面和五个字段以上方完整任务为准，不改变输入输出或范围。手工写出 n=1、n=5 的输出和最后一次失败判断时的 i，再运行核对。能独立完成者补充一句说明：“为什么输出恰好 n 行？”
