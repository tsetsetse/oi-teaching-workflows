# 自编验证题：相同数对

这是一道用于工作流验证的自编题，不是 GESP 或 CSP 真题。

给定 n 个整数 a[1]...a[n]，统计满足 1 <= i < j <= n 且 a[i] = a[j] 的数对个数。
输入：第一行 n，第二行 n 个整数。
输出：一行一个整数，表示数对数量，不输出提示语。
范围：1 <= n <= 200000，1 <= a[i] <= 1000000000。
样例：输入 `5\n2 1 2 2 1\n`，输出 `4\n`。

评分采用三组子任务，每组必须全部通过才得该组分数，三组相加：
- S1：30 分，n <= 2000，数值没有额外限制。
- S2：20 分，所有 a[i] <= 100，n 没有额外限制。
- S3：50 分，没有额外限制。
各组计分一次。只有上述公开规则，没有正式隐藏测试文件；不得把本地测试称为正式得分。
要求用学生能读懂的 C++14，保留不同建模视角、有意义的分层方案、每层完整可运行代码和独立验证证据；交互演示按教学难点选配。
