# 自编课后作业：循环次数与边界

本目录所有题目、学员代号、作答与观察均为合成验证材料，不对应真实学生、考试或课堂。

课程为40分钟循环入门，目标是理解初始化、先判断、执行、更新、再判断。已学整数变量、加减赋值、cin/cout、换行、比较<、<=、>=，本课引入for及i++；不使用数组、main以外函数或其他循环。以下是原始任务，保留不改。

## Q1 重复问候

输入一个整数n，输出恰好n行Hello，大小写与换行一致，不输出提示语。

- 输入：一行整数n。
- 输出：n行，每行只有Hello。
- 数据范围：1≤n≤5，C++14，标准输入输出。
- 样例输入：3。
- 样例输出：三行Hello，每行结尾换行。

样例输入：

```text
3
```

样例输出：

```text
Hello
Hello
Hello
```

## Q2 读程序

只作答，不必提交完整程序。已知n=3，循环为 `for(int i=0;i<n;i++)`，每轮输出当前i并换行。写出全部输出，说明一共执行几次，停止判断时i为多少。
